## Regra Principal

CAIRN deve parecer um ecommerce retail real de uma marca outdoor premium plausivel. Evite solucoes que parecam template generico, landing page conceitual, portfolio visual sem produto ou UI futurista sem fundamento comercial.

## Observacao Sobre Idioma

A documentacao do projeto deve ser escrita em portugues para facilitar entendimento e manutencao. O codigo, nomes de arquivos, componentes, rotas, branches e commits devem ser escritos em ingles conforme os padroes do projeto.
