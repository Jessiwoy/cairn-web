# Principios de UX/UI

## Norte de Experiencia

A experiencia deve priorizar descoberta, comparacao, decisao e compra. Beleza visual deve reforcar confianca e clareza, nao substituir funcionalidade.

## Principios

- O produto precisa aparecer cedo e com clareza.
- A navegacao deve ser previsivel.
- Categorias devem refletir comportamento real de ecommerce outdoor.
- Filtros, ordenacao e busca devem ser tratados como funcionalidades essenciais.
- O carrinho e checkout devem transmitir seguranca.
- Componentes devem ser reutilizaveis e consistentes.
- Estados de loading, vazio, erro e sucesso devem ser desenhados desde cedo.
- A experiencia deve parecer retail real, nao concept UI, dribbble concept, dashboard futurista ou landing page exagerada.

## Estrutura Visual

O design deve priorizar:

- Grids simples.
- Spacing forte.
- Poucas informacoes por viewport.
- Contraste limpo.
- Fotografia dominante.
- Hierarquia visual clara.
- Whitespace forte.
- Secoes amplas.
- Conteudo respirando.
- Visual editorial.

## Header/Navbar

O header deve ser inspirado na estrutura funcional da The North Face, sem copiar identidade proprietaria.

Caracteristicas:

- Preto predominante.
- Navegacao desktop visivel.
- Estrutura funcional.
- Poucos efeitos.
- Visual limpo.
- Sticky navbar.

Deve conter:

- Logo a esquerda.
- Categorias.
- Busca.
- Conta.
- Wishlist.
- Carrinho.

## Hero Section

O hero deve parecer uma campanha outdoor premium:

- Fotografia dominante.
- Pouco texto.
- CTA discreto.
- Composicao limpa.
- Poucas informacoes.

## Product Cards

Os cards de produto devem ter:

- Imagem dominante.
- Hover discreto.
- Pouca informacao.
- Spacing premium.
- Nenhum efeito exagerado.

## Motion Design

Utilizar:

- Fade discreto.
- Transicoes suaves.
- Microinteracoes leves.

Evitar:

- Motion exagerado.
- Animacoes longas.
- Efeitos chamativos.

## Responsividade

A estrategia deve ser mobile first. Mesmo assim, o pensamento visual deve considerar desktop premium ecommerce como experiencia principal de apresentacao.

## Paginas Esperadas

- Home retail
- Listagem de produtos
- Pagina de produto
- Carrinho
- Checkout
- Login e cadastro
- Conta do usuario
- Pedidos
- Favoritos ou wishlist
- Paginas institucionais essenciais

## Componentes Esperados

- Header com navegacao comercial
- Menu de categorias
- Product card
- Product gallery
- Price block
- Size/color selector quando aplicavel
- Rating/review summary
- Filters sidebar/drawer
- Cart drawer/page
- Checkout steps
- Account navigation
- Empty states
- Toasts ou feedbacks de acao

## Criterios de Qualidade Visual

- Layout deve funcionar em mobile e desktop.
- Textos nao podem estourar containers.
- A hierarquia visual deve facilitar scan rapido.
- O espaco em branco deve parecer intencional, nao vazio.
- Elementos interativos devem ter estados claros.
- A interface deve parecer utilizavel repetidamente, nao apenas bonita em screenshot.
